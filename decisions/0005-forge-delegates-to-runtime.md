# 0005. Forge는 LLM을 직접 부르지 않고 에이전트 런타임에 위임한다

- 상태: 채택됨
- 날짜: 2026-07

## 맥락
레거시 전환은 계획·실행·검증이 얽힌 긴 작업입니다. 본체가 모델을 직접 호출하면 모델 교체와 검증 게이트 관리가 어려워집니다.

## 결정
Forge 본체는 모델을 직접 부르지 않고 에이전트 런타임(PydanticAI 어댑터)에 위임합니다. 계획은 구조화 출력, 실행은 저장소 도구(Forgejo), 검증은 결정론 게이트로 나눕니다. 모델은 교체 가능한 부품으로 둡니다.

## 대안
- 본체에서 직접 LLM 호출 — 초기 구현은 빠르나 모델 종속·검증 배선이 취약.

## 결과
얻는 것 — 모델을 갈아 끼울 수 있고, 검증 게이트가 실행과 분리된다.

감수하는 것 — 런타임 계약(입출력 구조)을 잘 설계해야 한다. 자율 루프가 계약 게이트에서 수렴하지 못하면 직접 생성 루프로 폴백한다.
