# 0004. GUEST 유저는 개인정보를 수집하지 않는다

- 상태: 채택됨
- 날짜: 2026-07

## 맥락
외부 서비스(예: 안심회계봇)가 Hub를 채팅으로 붙여 쓸 때, 최종 사용자의 개인정보를 우리가 떠안으면 관리·규제 부담이 커집니다.

## 결정
채팅 전용 GUEST 유저 타입을 두고, 개인정보 없이 식별자만으로 매칭합니다. 외부 서비스에서 조립한 고정·고유 이메일로 GUEST 행을 즉시 생성하고, 같은 사용자에게는 항상 같은 식별자를 씁니다(멱등 매칭).

## 대안
- 정식 회원 수집 — 개인정보 보관·동의 관리 부담.
- 완전 익명 세션 — 이력·권한 관리가 불가능.

## 결과
얻는 것 — 개인정보를 수집하지 않으면서 GUEST도 정식 유저로 권한과 집계를 관리한다.

감수하는 것 — 식별자 생성 규칙을 외부 서비스가 정확히 지켜야 한다. 어긋나면 이력이 갈라진다.
