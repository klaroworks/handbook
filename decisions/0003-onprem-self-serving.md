# 0003. 모델을 온프레미스에서 자체 서빙한다

- 상태: 채택됨
- 날짜: 2026-02

## 맥락
공공·금융의 문서는 조직 밖으로 나가면 안 됩니다. 외부 클라우드 모델 API로는 이 요건을 맞추기 어렵습니다.

## 결정
vLLM·Ollama에 LoRA를 얹어 모델을 자체 서빙합니다. 외부 API 없이도 폐쇄망에서 단독으로 돌 수 있게 만듭니다.

## 대안
- 외부 클라우드 모델 API — 성능·운영은 편하나 데이터 반출이 발생해 규제 환경에 부적합.
- 하이브리드(민감 데이터만 온프레) — 경계 관리 비용이 크고 사고 표면이 넓어짐.

## 결과
- ✅ 데이터가 기관을 떠나지 않음 · 에어갭 운영 가능
- ⚠️ 모델 서빙·GPU 운영 부담을 우리가 진다. 온프레는 고객이 인프라를 조달·소유하는 구조로 완화.
