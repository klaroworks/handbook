# 의사결정 기록 (ADR)

중요한 기술·제품 결정을 **왜 그렇게 했는지**와 함께 남깁니다. 미래의 우리(그리고 합류할 동료)가 맥락을 되짚을 수 있도록.

형식은 [MADR](https://adr.github.io/madr/)를 따릅니다. 상태: `제안됨` → `채택됨` → `대체됨/폐기됨`.

## 템플릿
```
# NNNN. 제목
- 상태: 제안됨 | 채택됨 | 대체됨
- 날짜: YYYY-MM-DD

## 맥락
무엇이 문제였나.

## 결정
무엇을 하기로 했나.

## 대안
검토한 다른 선택지와 탈락 이유.

## 결과
얻는 것과 감수하는 것(트레이드오프).
```
