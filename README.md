# Klaro Field Guide — 우리가 어떻게 일하는가

주식회사 클라로가 제품을 만들고 일하는 방식을 공개합니다. 완성된 규칙집이 아니라 계속 고쳐 쓰는 문서입니다.

왜 공개하느냐면, 우리가 만드는 것이 근거·승인·감사가 남는 AI이고 그 밑바탕이 투명함이기 때문입니다. 같은 기준을 우리 자신에게도 적용합니다.

> 주식회사 클라로 · Seoul · [klaroworks.ai](https://klaroworks.ai)
> AI가 문서·데이터·코드 업무를 수행하고, 사람이 검증·승인합니다.

| 근거 · Grounding | 승인 · Human-in-the-Loop | 감사 · Audit |
|---|---|---|
| 모든 산출물에 출처가 붙습니다. 원문 인용부터 SQL Diff까지. | 담당자 검토·승인이 워크플로에 들어 있습니다. | 모델·근거·승인·버전 기록. RBAC · PII 마스킹 · 온프레미스. |

## 이 문서에 없는 것

제품 내부 구현, 고객 데이터, 인프라 상세, 보안 설정값은 담지 않습니다. 어떻게 일하는지는 공개하되, 무엇으로 방어하는지는 공개하지 않습니다.
