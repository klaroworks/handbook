# Klaro Handbook — 우리가 어떻게 일하는가

주식회사 클라로가 **제품을 만들고 일하는 방식**을 공개합니다.
완성된 규칙집이 아니라, 계속 고쳐 쓰는 살아있는 문서입니다.

왜 공개하냐면 — 우리가 만드는 것이 **근거·승인·감사가 되는 AI**이고, 그 밑바탕은 *투명함*이기 때문입니다.
우리 스스로에게도 같은 기준을 적용합니다.

> **주식회사 클라로** · Seoul · [klaroworks.ai](https://klaroworks.ai)
> 우리는 **AI 노동 자동화 플랫폼**을 만듭니다 — AI가 문서·데이터·코드 업무를 수행하고, 사람이 검증·승인합니다.

## 이 문서에 **없는** 것

제품의 내부 구현, 고객 데이터, 인프라 상세, 보안 설정값은 담지 않습니다.
**"어떻게 일하는가"는 공개하되, "무엇으로 방어하는가"는 공개하지 않습니다.**
